# In-Development Game Inspired by Hearthstone Battlegrounds

This is an in-development game which was inspired by Hearthstone Battlegrounds.

## Overview

The main focus of this project is to learn server-based functionalities in a game. 

## Getting Started

To see the game in action, you will need to:
1. Start the server.
2. Then start the client.

## Current State

For now, this project isn't in a playable state. However, you can already navigate the menu and even start a game. In the in-game interface, you can perform simple and limited actions.
